# TextRelay 产品需求 v1.0

日期：2026-11-09。当前执行范围：云电脑实现、测试、验收、本地 Git；GitHub 登录、远程创建、推送和正式部署留待用户参与。

## 用户与目标

接收者只需统一首页和四位码，快速获取并原样复制文字。唯一管理员在后台整理、搜索和管理分享。场景为非敏感协作文字，无需接收者账号。

## 已确认行为

- 码严格四位 ASCII 字母/数字，区分大小写，前导零保留。首页不加载正文、标题或码表。
- 成功后只展示正文；保留换行、空格、制表符及原始复制文本。HTML 按文字显示。
- 管理员可增删改查、按标题正文子串或完整码搜索、分页、启停、自定或随机码、换码。
- 不同现存内容不重码，停用仍占码；换码/删除立即释放旧码。复用后旧持有者可读新内容，用户明确接受。
- 标题为后台字段，最大 120 字符；正文 1–102400 UTF-8 字节。保留全空白正文（纯文本也可以是格式数据），空字符串拒绝，标题不能全空白。
- 管理员密码初始化、登录、退出、改密及本机重置；固定 8 小时会话。
- 基础访问码/登录 IP 与全站限速，限流明确等待提示。

## 视觉与交互

浅色中性与克制的绿色，单输入框利于粘贴；手机不自动大写。后台桌面列表、手机卡片，编辑为桌面侧面板、手机全屏。提供加载、空态、搜索无结果、复制成功/失败、错误与旧码复用提示。原生 dialog 保持焦点和 Escape 退出，未保存内容需确认放弃。

## 验收范围

API 临时 SQLite 集成测试；真实 Chromium 的访客与管理员关键路径；1440/390/320 像素布局及复制测试；生产构建、依赖审计、原生 SQLite 驱动、备份恢复。Docker 与 Nginx 实机部署另需具备环境并经用户下一步授权。完整证据见 acceptance.md。

## 不包含

附件、Markdown 渲染、多管理员、自动过期、次数限制、历史码保留。当前不登录 GitHub、不创建远程、不推送、不连接或改变服务器。
